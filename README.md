# RealTimeChatApp  

A simple **real-time chat application** built using **Kotlin, Jetpack Compose, and OkHttp WebSocket**.  
This app demonstrates how to connect to a WebSocket server, listen for messages, and update the UI reactively with **StateFlow**.

---

## 🚀 Features
- Connects to a WebSocket server (`wss://echo.webSocket.events`)
- Listens for messages in real time using `WebSocketListener`
- Stores and updates chat messages with `MutableStateFlow`
- Built with **Jetpack Compose** for modern UI
- Modular design – easy to extend with more features

---

## 🛠️ Tech Stack
- **Kotlin**
- **Jetpack Compose**
- **OkHttp WebSocket**
- **Coroutines + StateFlow**
